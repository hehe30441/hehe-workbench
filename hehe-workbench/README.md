# 贺贺🎉🔆💐 个人生活管理工作台

> 一个完全本地化的个人生活管理工具，部署在 GitHub Pages 上，手机加主屏幕即可当 App 使用。

## ✨ 核心特性

- **🔒 零隐私泄露**：所有数据存在浏览器 localStorage，不上传任何服务器
- **📱 PWA 体验**：可加入手机主屏幕，像原生 App 一样使用
- **🎨 莫兰迪色系**：淡绿 + 淡黄主题，干净简洁不刺眼
- **⚡ 单文件部署**：核心就 1 个 HTML，零后端依赖
- **🔌 离线可用**：Service Worker 缓存，全部功能断网也能用

## 🚀 GitHub Pages 部署（3 分钟）

### 第一步：创建 GitHub 仓库

1. 登录 GitHub → `+` → New repository
2. 仓库名：`hehe-workbench`（或你喜欢的名字）
3. 类型：**Public**
4. 点 Create repository

### 第二步：上传文件

把下面这 2 个文件拖到仓库根目录（GitHub 网页上 Add file → Upload files）：

```
index.html
xlsx.full.min.js
```

> ⚠️ 注意：`xlsx.full.min.js` 必须在同目录（HTML 里引用了相对路径）。它来自 SheetJS 库，用于把记账数据导出 Excel。

### 第三步：开启 Pages

仓库页 → Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / root → Save

1-2 分钟后访问：
```
https://你的用户名.github.io/hehe-workbench/
```

### 第四步：手机加入主屏幕

**iPhone Safari**：
1. Safari 打开上面网址
2. 点底部「分享」按钮
3. 选「添加到主屏幕」
4. 桌面出现「🎉🔆💐」图标 ✅

**安卓 Chrome**：
1. Chrome 打开网址
2. 弹窗或菜单里「安装应用」/「添加到主屏幕」

加完后从桌面图标打开 → 全屏显示，跟原生 App 一样！

## 💡 使用说明

### 视频爆点拆解怎么用？
抖音/小红书/B站视频都有字幕或口播文案。**把视频里的字幕文本复制粘贴进来**，系统会基于关键词规则自动识别：
- 悬念钩子（你知道吗、竟然、没想到）
- 数字冲击（95%、万、第一）
- 情绪共鸣（哭了、破防、心疼）
- 反差对比（但是、然而、别人）
- 干货价值（方法、技巧、步骤）
- 痛点刺激（痛点、踩坑、血亏）
- 互动引导（评论、你觉得）

并自动给出可改编方向（如"放大情绪点，评论区引导同类故事分享"）。

> 因为纯静态站点无法跨域抓视频内容，所以用粘贴文案的方式处理——既稳定又零依赖。

### 数据备份
左下角「💾 导出备份」→ 下载 JSON 文件 → 存到网盘或电脑
左下角「📥 导入恢复」→ 选择之前的 JSON 文件 → 还原

### 记账导出 Excel
记账模块右上角「导出Excel」→ 自动下载 xlsx 文件

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript（零框架）
- [ECharts 5](https://echarts.apache.org/) - 数据可视化（CDN引入）
- [SheetJS](https://sheetjs.com/) - Excel 导出（本地 xlsx.full.min.js）
- Service Worker - PWA 离线缓存（HTML 内联实现）
- localStorage - 数据持久化

## 📝 注意事项

- **定期导出备份**：浏览器清理缓存可能丢失数据，建议每周备份一次
- **同一浏览器使用**：localStorage 是按浏览器+域名隔离的，换浏览器需要导入备份
- **私密数据放心用**：所有内容只存在你的设备，不上传服务器

## 反馈建议

直接修改 `index.html` 即可定制。代码注释清晰，模块化结构，新模块只需在 `MODULES_DEF` 数组添加定义 + 写一个 `renderXxx` 函数即可。
